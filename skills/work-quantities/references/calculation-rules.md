# Выбор формул по исходным данным

Это примеры геометрических расчётов. Методика конкретного вида работ определяется заданием и его исходными данными.

| Задача | Формула | Условия применения |
| --- | --- | --- |
| Длина трассы | L = сумма длин выбранных кривых | Указать плановую или пространственную длину, правила учёта вставок и участков |
| Площадь покрытия | A = площадь объединения границ минус исключаемые участки | Проверить отверстия, перекрытия и замыкание границ |
| Объём слоя | V = сумма Aᵢ × tᵢ | Для каждой зоны задана постоянная толщина tᵢ, площади зон согласованы |
| Прямоугольная траншея | V = сумма Lᵢ × bᵢ × hᵢ | Сечение участка постоянно, пересечения и колодцы учтены по методике |
| Траншея с откосами | V = L × h × (bниж + bверх) / 2 | Постоянное трапецеидальное сечение, известны обе ширины и глубина |
| Между соседними сечениями | V ≈ L × (A₁ + A₂) / 2 | Метод средних концевых площадей, указать его приближённость и интервалы |
| Объём 3D-тела | V по API тела | Проверить единицы, корректность тел, перекрытия и границы вида работ |
| Количество элементов | N = число учтённых элементов | Учитывать кратность вставок, вложенность, массивы и исключённые обозначения |

Для переменной толщины или глубины используй обоснованное разбиение, сечения либо модель поверхности, соответствующие заданию. Среднюю толщину применяй при наличии её источника и основания.

Пример перевода единиц для слоя постоянной толщины — площадь 12 000 000 мм² равна 12 м². При толщине 150 мм = 0.15 м объём равен 12 × 0.15 = 1.8 м³. В рабочем расчёте сохраняй фактические значения и ссылки на их источники.
