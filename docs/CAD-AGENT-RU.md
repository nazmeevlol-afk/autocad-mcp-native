# CAD Agent для Codex

Персональное дополнение к [AutoCAD MCP Native Bridge](https://github.com/Yimmingyang/autocad-mcp-native). Лицензия исходного проекта MIT сохранена в `LICENSE`.

Плагин объединяет готовый MCP-сервер и два русскоязычных навыка — `as-built-drawings` для исполнительных схем по образцу и `work-quantities` для расчётов с формулами и источниками данных.

## Локальная установка

Нужны Windows, Node.js 20+, Codex и совместимый AutoCAD с загруженным мостом. Для AutoCAD 2025 используется .NET 8. Сборка моста под установленный AutoCAD описана в исходном `README.md` и `scripts/Build-AutoCADPlugin.ps1`.

В каталоге клона выполните команды по очереди.

```powershell
npm ci
npm test
npm run check
codex plugin marketplace add .
codex plugin add cad-agent@nazmeev-cad
```

Локальная установка плагина должна включать `node_modules` с зависимостями MCP. После изменения исходников или зависимостей переустановите локальный плагин, чтобы обновить установленную копию. Запуск выполняет `scripts/Start-CadAgentMcp.ps1`. Он использует `CAD_AGENT_NODE`, затем `node` из PATH, затем переносной Node в `C:\CAD-Agent\runtime\node-v*-win-x64`. Значение `CAD_AGENT_NODE`, если оно требуется, должно быть полным путём к `node.exe` в окружении запуска Codex.

Откройте новый локальный чат Codex после установки и выберите CAD Agent. Проверьте доступность инструментов, вызовите `get_bridge_status`, затем `list_tools`. Если AutoCAD ещё не запущен с загруженным плагином, MCP-сервер может успешно запуститься, а запрос к AutoCAD вернёт ошибку подключения. Установку моста в AutoCAD выполняют отдельно от регистрации плагина Codex.

Успешное получение каталога MCP проверяет связь клиента с сервером. Проверку геометрии выполняйте на отдельном тестовом DWG. При повторном подключении убедитесь, что сервер направлен на требуемую версию и экземпляр AutoCAD.

## Использование

Примеры запросов после подключения.

- «По образцу DWG создай исполнительную схему участка по приложенным фактическим координатам. Сохрани результат отдельным DWG».
- «Рассчитай площади покрытия и объёмы слоёв. Покажи контуры, исходные толщины, единицы и формулы».
- «Сверь ведомость с чертежом и перечисли строки с недостающими исходными данными».

Для оформления нужен образец DWG/DWT или PDF. Для фактической геометрии нужны координаты, размеры и отметки. Для расчётов нужны виды работ, правила учёта и параметры, которые отсутствуют в геометрии. Конкретные шаблоны и правила объекта добавляются после получения образца пользователя.

## Границы проверки

Навыки задают рабочий процесс. Фактические возможности операций определяются загруженным AutoCAD-плагином. Поддержка листов, внешних ссылок, печати и особенностей конкретного DWG проверяется на рабочем образце. Численные итоги и оформление должны сопровождаться выполненными проверками и сведениями о недостающих данных.
